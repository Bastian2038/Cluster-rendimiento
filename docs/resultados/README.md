# Índice de resultados de rendimiento

Este repositorio no contiene resultados observados de inferencia, serving, SFT ni escalamiento de Qwen. Tampoco presenta una captura de inventario como benchmark. Al ejecutar campañas autorizadas, indexar cada resumen con `run_id`, fecha, hosts observados, commit, modelo/revisión, configuración, definición de métricas y enlace a evidencia raw cerrada; mantener los derivados fuera de raw.

Pegasus será el único baseline single-node. Una comparación con Pegasus + Octopus requiere su Pegasus-only contemporáneo y pareado; cuatro nodos permanecen como topología futura. Ver [metodología](../metodologia-rendimiento.md), [inventario](../inventario-pegasus.md) y [reproducibilidad](../reproducibilidad.md).
